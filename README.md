# 🎄 Christmas Party 2025 Planning Central

A comprehensive web-based party planning application to help you organize the perfect Christmas celebration!

## Features

### 🏠 Homepage
- **Party Details Dashboard**: View and edit party date, time, and venue
- **Quick Statistics**: Track guest count, tasks completed, budget status, and days until the party
- **Recent Activity Log**: Keep track of all planning updates

### 👥 Guest List Management
- **Interactive Guest Table**: Add, edit, and delete guests
- **RSVP Tracking**: Monitor confirmed, pending, and declined responses
- **Guest Details**: Store contact information, dietary restrictions, and +1 status
- **Search & Filter**: Easily find guests by name, email, or phone
- **Filter by RSVP**: View guests by their response status

### ✅ Checklist
- **Categorized Tasks**: Organized by:
  - Venue & Logistics
  - Entertainment
  - Food & Beverages
  - Decorations
  - Invitations & Communication
  - Photography & Memories
- **Progress Tracking**: Visual progress bar showing completion percentage
- **Custom Tasks**: Add your own tasks to any category
- **Task Management**: Check off completed tasks and delete unnecessary ones

### 📅 Planning Dashboard
- **Budget Tracker**:
  - Set and track your total budget
  - Add expenses by category
  - Visual budget usage indicator
  - Detailed expense breakdown
- **Timeline View**: Pre-planned milestones from 3 months before to party day
- **Planning Notes**: Save important notes and ideas

## Getting Started

### Installation
1. Clone or download this repository
2. Open `index.html` in your web browser
3. No server or installation required!

### Usage
- Navigate between pages using the navigation bar
- All data is stored locally in your browser (localStorage)
- You can edit party details, manage guests, track tasks, and monitor your budget
- Data persists between sessions

## Tips for Party Planning

### 3 Months Before
- Set your date and budget
- Create your guest list
- Book the venue

### 2 Months Before
- Send save-the-dates
- Book caterer and entertainment
- Order decorations

### 1 Month Before
- Send formal invitations
- Confirm all vendor bookings
- Finalize menu and activities

### 2 Weeks Before
- Follow up on RSVPs
- Finalize headcount
- Confirm dietary requirements

### 1 Week Before
- Final vendor confirmations
- Prepare party favors
- Create setup schedule

### Day Before
- Decorate venue
- Set up tables and seating
- Test all equipment
