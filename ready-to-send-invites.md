## How to Send with Calendar Invite

### Option 1: Text + Calendar File
1. Send the text message first
2. Follow up with: "Calendar invite attached!"
3. Attach the `christmas-party-2025.ics` file

### Option 2: iMessage (iPhone to iPhone)
1. Copy the text message
2. Send via iMessage
3. Tap the + button and attach the .ics file from your Files app

### Option 3: MMS (Works for all phones)
1. Send the text message
2. Download the .ics file to your phone
3. Share it via MMS to each contact
